## Turbowarp/HTML Project Advisories (November 18th, 2026)

My projects that could have possibly been effected have mostly been removed from github.com, but it is recommended to exercise caution, as you always should online. Additionally, I am a hobbyist, not a large corporation. As stated in previous repositories, if you choose use my software, it is at your own risk.
